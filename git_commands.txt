====================================================
  Git Commands Used - Assignment Documentation
====================================================

1. mkdir git_assignment
   - Creates a new project folder named 'git_assignment' on the local machine.

2. cd git_assignment
   - Changes the current working directory into the project folder.

3. git init
   - Initializes a new, empty Git repository in the current folder (creates the hidden .git directory).

4. git config user.name "Student"
   - Sets the author name to be used for all commits in this repository.

5. git config user.email "student@bits.com"
   - Sets the author email to be used for all commits in this repository.

6. git add index.html about.html
   - Stages specific files (index.html and about.html) so they are ready to be committed.

7. git add .gitignore
   - Stages the .gitignore file for the next commit.

8. git add contact.html
   - Stages the contact.html file for the next commit.

9. git commit -m "Initial commit: Add index.html and about.html"
   - Records the staged changes as the first commit in the repository with a descriptive message.

10. git commit -m "Update index.html: Add more descriptive content to home page"
    - Records the second commit after modifying index.html.

11. git checkout -b feature
    - Creates a new branch named 'feature' and switches to it immediately.

12. git checkout main
    - Switches back to the 'main' branch from the 'feature' branch.

13. git merge feature
    - Merges the 'feature' branch into the currently active branch (main), combining their histories.

14. git reset --soft HEAD~1
    - Undoes the last commit but keeps the changes staged (ready to be recommitted).
      HEAD~1 means "one commit before the current HEAD".

15. git log --oneline --graph --all
    - Displays a compact, visual commit history showing all branches and their relationships.

16. git status
    - Shows the current state of the working directory and staging area (modified, staged, untracked files).

17. git remote add origin <URL>
    - Links the local repository to a remote GitHub repository at the specified URL.

18. git push -u origin main
    - Pushes the local 'main' branch to the remote repository on GitHub.
      The -u flag sets the upstream tracking so future pushes just need 'git push'.
